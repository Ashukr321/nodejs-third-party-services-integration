# Use Cases - Authentication & OAuth 🔐

OAuth and Authentication providers simplify user management and improve security.

### 1. Social Login (Social Auth)
Allowing users to sign up/in using their existing accounts.
- **Examples:** Login with Google, GitHub, Facebook, or Apple.

### 2. Single Sign-On (SSO)
One set of credentials to access multiple related but independent software systems.
- **Examples:** Using a corporate Google account to log into Slack, Zoom, and Jira.

### 3. API Access (Third-party Integration)
Requesting permission to access a user's data on another platform.
- **Example:** A calendar app requesting access to your Google Calendar.

### 4. Machine-to-Machine (M2M) Auth
Secure communication between two services without user intervention.
- **Example:** A backend service fetching reports from a data analytics platform.
