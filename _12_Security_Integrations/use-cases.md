# Use Cases - Security Integrations 🛡️

Protecting your application, data, and users from malicious actors.

### 1. Data Encryption
Protecting sensitive information at rest (database) and in transit (SSL/TLS).

### 2. Secrets Management
Safely storing API keys, database passwords, and private keys.
- **Example:** AWS Secrets Manager, HashiCorp Vault.

### 3. Dependency Scanning
Automatically checking your `package.json` for libraries with known security vulnerabilities.
- **Example:** Snyk, GitHub Dependabot.

### 4. Bot Detection
Differentiating between real users and malicious scripts or crawlers.
- **Example:** Google reCAPTCHA, Cloudflare Bot Management.

### 5. API Security (WAF)
Protecting your endpoints from SQL injection, Cross-Site Scripting (XSS), and other OWASP Top 10 threats.
- **Example:** Cloudflare, AWS WAF.
