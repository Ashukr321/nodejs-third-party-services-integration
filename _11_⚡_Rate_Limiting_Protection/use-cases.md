# Use Cases - Rate Limiting & API Protection ⚡

Protecting your server from abuse and ensuring fair usage.

### 1. Brute Force Protection
Limiting login attempts to prevent hackers from guessing passwords.

### 2. DDoS Mitigation
Blocking high-frequency requests from a single IP address that could crash your server.

### 3. API Tiering (Monetization)
Allowing Free users 100 requests/day and Pro users 10,000 requests/day.

### 4. Protecting Expensive Resources
Limiting access to APIs that cost you money (e.g., OpenAI, Google Maps).

### 5. Scraping Prevention
Making it difficult for bots to scrape your content by limiting rapid page loads.
