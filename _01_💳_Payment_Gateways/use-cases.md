# Use Cases - Payment Gateways 💳

Payment gateways are critical for any application that needs to process financial transactions securely.

### 1. E-commerce Checkout
The most common use case where users pay for physical or digital goods.
- **Example:** Amazon, Shopify.
- **Workflow:** Add to cart -> Checkout -> Payment -> Order Confirmation.

### 2. Subscription Billing (SaaS)
Handling recurring payments on a weekly, monthly, or yearly basis.
- **Example:** Netflix, Spotify, Slack.
- **Workflow:** Choose plan -> Authorize card -> Automated recurring charges -> Invoicing.

### 3. Marketplace Payouts
Facilitating payments between buyers and sellers, often taking a commission.
- **Example:** Airbnb, Uber, Etsy.
- **Workflow:** Buyer pays marketplace -> Marketplace holds funds -> Payout to seller (minus fees).

### 4. Donations & Crowdfunding
Allowing users to contribute funds to causes or projects.
- **Example:** Kickstarter, GoFundMe.
- **Workflow:** Select amount -> Payment -> Milestone tracking.

### 5. In-App Purchases
Selling digital content or features within a mobile or web application.
- **Example:** Gaming currency, premium features.
